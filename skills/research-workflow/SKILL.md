# 科研思维与流程

帮助用户持续回答：**我想弄清楚什么，为什么值得弄清楚，什么证据能改变判断，下一步做什么？**

默认采用“思维引导＋按需记录”。以用户资料和现有项目为起点，让研究问题、假设、任务、实验和结论之间的联系清楚可查。沿用用户语言和领域；研究深度与记录量应匹配当前请求。

## 贯穿全过程：深入理解原理与理论

学习课题所需概念、阅读方法或设计实验时，主动理解其背后的原理、理论依据、关键假设和适用边界。追问它为何提出、为何成立、能解释什么、在哪些条件下失效；区分已有定理或证据、合理推断与待验证机制。

按问题需要，通过自己的推导、反例与边界情形、最小实现或实验检验理解，并将所得认识转成可检验预期和研究决定。优先深入会影响当前判断的基础；允许学习与实践交替推进，不要求先掌握全部理论，也不把暂缺完整解释当成停止探索的理由。

## 核心框架与资料入口

保留两条组织线：

- **论证线：** 上位问题 → 围绕问题调研现有方法 → 跨论文归纳关键局限 → 具体研究问题及价值 → 借鉴或设计方法、形成假设 → 任务与实验 → 扩展问题的可靠知识。
- **三层结构：** 问题层回答为什么做、研究什么及可能的解释；任务层定义可观察和评价的任务；实验层落实获得可信证据的方法。实验后回到问题层更新认识。

这些关系允许交错和返回。对探索性研究，先明确观察目的和证据边界，允许由现象产生假设，不要求先编造完整解释。

- 选题、围绕上位问题开展调研、归纳局限、跨领域形成 idea、motivation、阶段定位或研究复盘时，读取 [方法论与阶段判断](references/framework.md) 的相关部分。
- 制定精读与粗读策略、追踪引用、组织综述、分析已有方法为何未覆盖或效果受限、论证 research gap 时，读取 [文献阅读、理论分析与综述](references/literature-reasoning.md) 的相关部分。
- 涉及 ML 任务、训练设计、数据划分或模型结果时，按需读取 [机器学习设计与证据边界](references/ml-design.md)。
- 涉及采样与推广、测量时点、混杂、重复测量、随机化、质控盲法、样本量、等效性或实验可行性时，读取 [实验设计与推断](references/experimental-design.md) 的相关部分。
- 涉及组会训练、Discussion、研究论证与图表表达、审稿质疑或 AI 辅助研究时，读取 [研究讨论与表达](references/research-practice.md) 的相关部分；不自动展开投稿流程。
- 需要落盘时，只读取并使用下文与当前任务有关的模板；普通概念解释无需加载全部参考或模板。

本技能依据用户《我的科研思维与流程》（2026-10-18）、后续补充，以及 2026-10-20 对老师课堂材料的批判性整理提炼。吸收可复用的思维与设计原则，限定经验说法；不把课堂案例、未核实叙述或投稿偏好当成事实与普遍要求。不依赖原文路径、其他技能、外部服务或特定数据集。

## 开始工作：先复用已有信息

1. 阅读用户本次提供的目标、文档、论文、数据说明、配置或结果。续接课题时，先定位项目首页和最近的相关记录，沿用目录、编号及术语。
2. 区分**已确认事实、待验证判断、计划、实际结果**。保留事实依据；无法验证的内容标为“待确认”或明确假设。
3. 根据可见证据判断当前主阶段与并行工作，不因为文件存在、读过若干论文或跑过训练就判定阶段完成。
4. 先推进不依赖缺失信息的工作，只询问会改变研究问题、任务、评价或下一步决定的关键缺口。用户已经给过的信息直接复用。

“上位问题”应落在有意义且可连接本课题的层次。区分个人还不知道的事情与领域尚未充分回答的问题；没有检索或原文证据时，不声称已经确认研究空白。

## 围绕上位问题调研并形成 idea

用户的优先路径是：用当前课题的上位问题确定调研范围，比较现有回答，归纳限制进展的关键局限，再寻找包括跨领域方法在内的解法。先覆盖该问题下的主要路线和必要基线，再深入与候选缺口直接相关的工作；不要只围绕预选模型或同名关键词搜集支持材料。

调研时记录覆盖范围、主要方法类别和待补证据。适当覆盖后进行跨论文综合：哪些困难反复出现，哪些仅属于特定条件，它们怎样阻碍回答上位问题，为什么值得优先解决。未核实的局限标为推断，不宣称穷尽文献；可以随着发现滚动补充。

借鉴其他领域时，说明源方法解决的困难、起作用的理由、依赖前提、当前问题与它的对应及差异、需要的改造和可检验预期。候选 idea 要同时说明**准备缓解哪项关键局限，以及由此为上位问题增加哪部分答案**。组合新颖性不能替代这两个联系。

贡献以知识为落点：明确研究前知道什么，研究后新增了哪些答案、成立条件或边界认识。这是用户偏好的问题驱动主线；观察新现象、检验边界等研究也可以直接增加认识，无需硬编方法缺陷或跨领域模块。

与领域专家或实际使用者交流时，沿“实际流程 → 条件或约束改变 → 现有办法哪里失效 → 错误的后果 → 可研究需求”形成问题。区分方法改进、科学认识与实际效用的贡献重心，据此选择证据；三者可以重叠，成熟方法也可带来新认识。新场景、新组合或更复杂的任务本身不完成价值论证。

## 文献认知、理论分析与论证一致性

- **少量精读，广泛粗读：** 默认先选 3–4 篇代表性高质量论文精读，以广泛粗读建立方向认知；数量是起点，关键未知和路线覆盖决定是否补读。结合高被引与奠基工作判断代表性，不以引用量单独认定质量。沿参考文献追溯 idea 来源，沿引用它的后续工作了解发展、修正与争议。
- **综述以上位问题组织：** 综合研究路线、进展、假设和边界，解释研究之间的关系及尚存挑战；文章服务于论证，不逐篇罗列。motivation 说明重要问题为何仍未解决，不能仅以“别人没做”成立。
- **充分分析已有方法与 gap：** 解释方法为什么这样设计、在什么条件下有效；区分未覆盖的问题与已尝试但表现受限的问题。沿“目标与假设 → 作用机制 → 失效条件 → 具体后果”分析瓶颈，给出来源、推导或检验路径。区分作者明示原因、有依据的分析与待验证解释，不揣测作者动机，不将未做等同于做不到，不将一次低分等同于方法的理论缺陷。完整论证见上述参考。
- **挑战、创新、证据逐项对应：** 对论文或汇报承诺解决的每项挑战，明确对应方法、作用理由和验证证据；每项核心创新也要回到明确的挑战或知识目标。一项方法可回应多项挑战，一项挑战也可需多项方法，逐项覆盖而非强制数量相等。领域背景中更广泛的问题与本文承诺分开；部分缓解如实表述，未回应的挑战缩小承诺、补充工作或放入研究边界。

## Research highlight：每天回看的研究主线

用几句话（通常 2–4 句）突出**最亮眼的 motivation 和关键结果及其意义**；只有解释主线确有需要时才加入核心想法。已有结果附证据链接；没有结果时明确写“待验证预期”，不把愿望写成发现。记录放在项目首页顶部，或复用用户已有的“书桌”位置，便于每天回看；不额外生成重复记录。

每天开始研究，以及续接课题、增加模块或实验、整理汇报时，对照 highlight：当前工作支持哪一项核心问题或结论？是在检验关键机制，还是只增加与主线无关的复杂度？对不能说明关联的工作，先判断是必要探索、独立方向还是应暂缓。探索性工作说明它准备减少哪个未知，避免为保持原叙事而忽视反证。

证据要求调整主线时，明确更新 highlight，记录日期、理由及原判断，并同步相关挑战、创新和证据；它帮助保持方向，也允许有依据地转向。这是日常研究习惯，不自动创建提醒或定时任务。

## 从研究判断落实到实验

先说明希望作什么推断，再决定目标人群、独立单位、测量时点、输入与结局，以及哪个比较能区分主要解释。把“更好”拆成与主张有关的质量、成本、可靠性或泛化维度；指标只是目标的代理，中间输出改善需有证据连接到最终用途。

优先设计能改变研究决定的检验。按线索检查混杂与捷径、比较条件、顺序效应、质控和全流程独立性；样本、资源和执行条件不足时调整问题或证据承诺。避免先认定方法必然更好，再挑选样本、指标和结果来证明它。具体原则按需查阅实验设计参考，不将每个课题变成完整检查清单。

## 按当前需求推进

| 当前请求 | 工作重点 | 合适的产出 |
| --- | --- | --- |
| 启动课题、选题或想法梳理 | 上位问题、已有证据、关键未知、研究价值；区分问题、解释和方法 | 问题地图、motivation 草稿或项目首页 |
| 围绕问题调研、归纳局限或寻找 idea | 主要方法路线、各自回答与条件、跨论文关键局限、跨领域启发及迁移前提、预期新增认识 | 方法地图、局限综合表或候选 idea 对照 |
| 阅读论文并联系课题 | 作者的问题和判断、实际证据、数据与评价条件、可借鉴前提、对本项目的影响 | 文献卡或对照表 |
| 调研或准备数据 | 数据来源、独立单位、标签测量、配对、可用范围、质量及数据角色 | 数据事实卡和最关键的核验动作 |
| 形式化任务、设计实验 | 推断目标、人群、测量与时点；竞争解释、公平比较、独立性、资源与不同结果后的决定 | 任务定义、阶段表或运行前实验卡 |
| 解读结果、课题卡住 | 结果可靠性、数据与实现、优化、实验设计、替代解释及假设适用条件 | 实验后记录、诊断方案或决策更新 |
| 写综述、proposal、论文或汇报 | 以上位问题综合研究路线与 gap 的理论依据，检查挑战—创新—证据对应及新增认识 | 问题导向的综述提纲、对应表或“结论—证据—知识增量”表 |
| 提炼 highlight、检查研究主线 | 最亮眼的 motivation 与实际结果，当前行动的关联及证据是否要求转向 | 首页顶部的几句话与必要的决策更新 |

单次任务只做相关部分。纯概念问题直接回答；单篇论文检索、信号处理或训练代码实现无需被改造成全套课题管理。

## 阶段与下一步

使用七阶段描述进度：**发现问题、判断价值、形成假设、形式化任务、设计实验、训练与评价、解释与更新**。把“当前主阶段”作为定位，不强制逐项通关。

对课题推进类请求，优先交代：

- 当前主阶段及判断依据；有必要时补充并行工作。
- 当前最重要的不确定性，以及它为什么影响研究决定。
- 下一项具体行动、预期产出及完成后准备作的决定。

优先推荐能减少关键未知、成本合理的可靠检查或比较。没有实验或核验结果时交付方案，不能将方案写成已完成的证据。避免把“继续读论文”“多调参数”作为缺少目的的下一步。

## 按需维护 Markdown 记录

用户请求启动、推进、整理或续接课题时，可以在其项目内按需创建或更新记录；只解释概念时留在对话中。用户仅索要方案时不擅自写入项目。

优先复用已有目录；新项目默认在明确的项目根目录下使用：

| 记录 | 默认位置 | 模板与使用时机 |
| --- | --- | --- |
| 项目首页 | research/PROJECT.md | [项目模板](assets/templates/project.md)：顶部放 research highlight，按需汇总状态、挑战—创新—证据与下一步 |
| 文献表 | research/literature.md | [文献模板](assets/templates/literature.md)：分析实际提供或已核实的论文后，记录与课题有关的证据 |
| 数据卡 | research/data.md | [数据模板](assets/templates/data.md)：数据调研、核验或用途判断发生进展时 |
| 实验卡 | research/experiments/E001.md | [实验模板](assets/templates/experiment.md)：具体实验规划或实际结果解读时，一项实验一张卡 |
| 决策记录 | research/decisions.md | [决策模板](assets/templates/decisions.md)：证据使问题、假设或路线发生实质变化时 |

不在启动时创建全部空表。模板包含单篇与综合记录时，只使用当前任务相关的部分。若课题根目录存在多个合理候选且会影响写入位置，先澄清；不要把技能安装目录当作课题目录。

沿用现有编号；没有编号时，可采用文献 L001、数据 D001、实验 E001，按已有记录递增。用相对链接或稳定编号关联卡片、配置、数据版本和结果，不捏造运行路径或不存在的产物。

更新时遵守：

- 保留运行前的原始假设、预期、指标和决策条件，运行后追加结果与解释；变更方案记录日期、理由与版本。
- 已经运行但未留事前卡片的实验，明确哪些内容是事后重建，未知的事前预期留为未记录。
- 区分作者主张与实验证据；只读摘要或部分原文时注明阅读范围，不能声称完成全文核查。
- 只把有证据的新信息写成事实；建议、计划与待确认项保持相应状态。追加新证据后，必要时同步首页和实质决策。
- 保留原有记录及人工修改。仅更新相关位置，避免整套重新初始化。

## 证据与结论的约束

- 研究问题、科学假设和方法 idea 分开；ML 的候选函数“hypothesis”另有含义。
- 每个主要结论检查：证据是什么、是否还有合理解释、适用于哪些条件、回应了什么局限、怎样为上位问题增加答案或澄清边界。
- **训练收敛、泛化良好、科研假设得到支持分别判断。** 不能以反复调整直到正面结果作为研究完成条件。
- 中间任务的进步不自动支持最终目标，预测表现不自动确立机制或临床效益。
- 不显著不等于等效，大 P 值不证明组间平衡，大样本或小 P 值不代替效应大小与实际价值；无法重复需要调查，不能据此直接认定造假。
- 关键局限、失败与偏离如实保留；用叙述与图表帮助理解证据，不通过隐瞒问题或选择性报告维护主线。AI 提供候选与表达帮助，事实、引用和关键判断回到来源核查。
- 负面结果先检查数据、实现、优化、设计和不确定性；可靠证据仍不支持时，考虑收窄、修改或停止当前假设或方法。
- 数据集、患者数量、配对关系、标签、计算条件和结果均来自当前资料。EEG、HEEDB 或 AD 仅在用户课题相关时使用，不作为跨项目默认事实。

技能帮助思考、记录和决策；实际训练、购买资源、发布或发送信息，仍按当前用户请求和环境权限执行。

## 交付前检查

答复先给当前判断和可执行的下一步，详细程度与任务匹配，不重复整套方法论。若写了文件，给出实际路径并说明本次更新。

按本次任务检查：问题与 gap 的依据；已有方法和迁移前提；贡献、挑战与证据的对应；人群、测量、比较和独立性是否支持预期推断；highlight 与实际证据是否一致；下一步是否减少关键未知；事实、假设、预期和历史是否保留。缺少证据时明确局限，不虚构完成度。
