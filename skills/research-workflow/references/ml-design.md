# 机器学习研究：任务、学习过程与证据

仅在相关课题涉及 ML 时使用。重点章节：任务与测量、数据划分、学习对象、多阶段目标、比较与诊断。以下领域示例均为条件性设计，不是数据集事实或已获得结果。

## 1. 从研究问题到任务与测量

先说明研究目标，再决定：

- 观测、抽样、预测和推断分别以什么为单位。
- 推理时实际可用的输入，输出及真实答案的定义。
- 标签或文本由谁、在何时、因为什么产生，代理测量与研究目标有什么距离。
- 训练监督来自标签、配对文本、数据自身或其他信息。
- 主要评价、选择协议、泛化对象和结果含义。

训练时可用的监督与推理时可用的输入分开。测试时不输入真实答案是通常的预测设定；是否零样本，要看是否使用了对应任务、类别或其他定义下的适配信息，不能仅因推理没有标签就宣称零样本。

模型输出格式不替代任务指标：文本形式的诊断应按定义评价诊断；分数输出应按测量含义处理。阈值、解析规则和失败输出的处理在开发中确定，不根据测试效果临时选择。

Data science、data mining 和 ML 有重叠，不应强制排成“清洗—挖特征—训练”三个领域。实际任务按需要安排工作，深度模型可能联合学习表示。

## 2. 明确学习中的对象

| 对象 | 含义 |
| --- | --- |
| 未知目标映射 $f$ | 希望学习的输入—输出关系；带噪现实常用 $P(Y\mid X)$ 描述 |
| 假设空间 $\mathcal H=\{h_\theta:\theta\in\Theta\}$ | 候选预测函数集合 |
| 拟合模型 $g=h_{\hat\theta}$ | 学习后得到的具体函数 |
| 损失 $\ell(\hat y,y)$ | 一次预测如何计分 |
| 训练目标 $J(\theta)$ | 聚合训练损失、正则等形成的优化准则 |
| 学习算法 | 根据数据、目标与配置得到模型的过程 |
| 优化算法 | 学习过程中参数更新的方法 |
| 评价指标 | 指定任务、数据和协议下的表现度量 |

训练目标示例：

$$
J(\theta;\mathcal D_{\mathrm{train}})
=\frac1n\sum_{i=1}^n \ell(h_\theta(x_i),y_i)+\lambda R(\theta).
$$

固定训练数据后简写为 $J(\theta)$。优化算法利用该准则更新参数，例如梯度下降：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t).
$$

目标规定优化什么，算法规定如何更新。目标还为优化提供依据，不能只称为训练后的评价分数。

训练目标与指标可以同形，也可以不同；区别在用途、数据角色及与研究主张的关系。未知的 target function 不是已定义可计算的 objective。

固定架构后的权重学习，本身就是在函数族中寻找函数。参数、架构、训练配置和验证选择共同影响结果；算法找到的解未必训练全局最优，训练最优也未必泛化最佳。

ML 中的 hypothesis 可指候选函数，科学假设则是待检验的解释或预测，二者不要混用。

## 3. 数据、预处理和泛化

从来源、层级、字段含义、标签依据、测量时间、配对、缺失和采集条件理解数据。数据读取成功不等于能够回答问题。

| 目标 | 需要考虑的评价独立性 |
| --- | --- |
| 新对象或患者 | 按独立对象分组，其相关记录和窗口不跨职责 |
| 未来时间 | 时间信息与预测时点一致，避免未来信息进入训练或输入 |
| 新机构、设备或队列 | 留出对应条件，说明是否使用其数据适配 |
| 新任务 | 明确训练见过什么任务、标签和指令，按相应迁移设定评价 |

更多相关窗口不等于更多独立患者。汇总单位、抽样和区间估计要匹配相关结构；不要把高度相关片段当成独立证据扩大置信程度。

预处理中的总体统计量、PCA、标签驱动特征筛选等，只用当前允许的训练信息拟合；交叉验证中在各训练折内完成。固定滤波或单记录变换也需符合实际推理条件，不能笼统禁止或默认安全。

训练拟合参数，验证选择配置、训练轮次和阈值，最终测试评价已确定的方案。验证通过选择影响模型；反复依测试修改后，测试已参与开发，需要新的确认或明确局限。

## 4. 多阶段学习

训练阶段与数据职责是两条轴：

- 阶段描述学习顺序、信号、参数更新与冻结。
- 数据职责描述训练、验证或测试用途。

预训练也需要验证安排，且要检查与下游测试对象、记录和文本的重叠。允许使用目标域无标签数据时，明确这种设定及其与未见目标数据泛化的差异。

最终测试通常不更新参数。研究测试时适配时，另行明确可用信息、参数更新和比较协议。

为相关方法填写：

| 阶段 | 学习任务与监督 | 训练目标 | 更新 / 冻结模块 | 预期能力 | 与最终任务的证据联系 |
| --- | --- | --- | --- | --- | --- |
| 依实际方案填写 |  |  |  |  |  |

目标任务数、阶段数和损失项数无需对应。不同任务可以共享生成损失，一个任务也可以有多个目标；采样比例、损失权重和答案长度会影响实际优化。

检查各阶段的必要性、能力传递和可能的遗忘或冲突。根据假设选择阶段比较、消融、单任务与多任务比较，不机械堆叠实验。

### 条件性的 EEG 示例

若实际拥有可用的 EEG–报告配对，可以研究对齐；若同时具有合适的目标临床标签，可以进一步研究下游价值。源任务存在对应信息，不保证信息可迁移到其他疾病；嵌入对齐也不保证语言模型会利用它。

检索表现回答对应能力问题，目标任务与标签预算比较回答预测价值或标签效率问题，输入干预提供模型依赖 EEG 的线索。这些证据不能互相替代。

HEEDB 或任何特定数据集的字段、患者数、文本和标签，都必须根据当前可访问资料核实。不能因示例路线而假设数据已具备。

## 5. 实验要区分合理解释

先确定问题、假设与竞争解释，再规划变化因素、基线、数据、评价、选择和预期结果后的决定。

公平比较关注可能解释收益的数据访问、监督量、样本构成、划分、模型规模、训练预算与选择机会。不能完全匹配时，写清差异并限定主张。

一些比较的用途与边界：

- 有无某类监督：评估新增监督在既定条件下的价值，说明资源差异。
- 不同标签预算：评价标签效率，同时报告预训练监督与选择成本。
- 正确与打乱配对：探查配对信息的作用，但打乱也可能影响训练难度。
- 正常与干预输入：调查模型依赖的信息，注意干预可能引入分布变化。
- 消融或阶段比较：检验设计贡献，收益不单独确立具体机制。
- 外部评价：检验实际留出条件，不自动推广到全部人群和部署环境。

初始化、数据抽样、评价样本不足及选择效应属于不同不确定性。依主张和数据结构选择重复、区间或分组分析，不规定普遍种子数量和显著性门槛。

## 6. 失败诊断与结论

按具体线索检查数据与测量、实现、优化、选择、评价和假设。小规模可信样本可以调查可训练性，不能证明泛化；修复前得到的差结果未必检验了研究假设。

研究追求足以更新判断的证据。训练损失降低、独立预测有效、解释性假设得到支持和临床有用，是不同强度的结论，需要各自的证据。
