# 数据事实与用途记录

每个数据集或关键子集使用一条编号；只把有来源的核实内容写为事实，其他内容标为待确认。

| 编号 / 数据 / 版本 | 来源与访问范围 | 独立对象、记录和派生样本层级及数量 | 标签 / 测量 / 文本含义 | 配对依据与时间关系 | 已核实质量、缺失及排除规则 | 候选用途与划分 / 跨数据重叠 | 证据位置与下一项核验 |

## 核验记录

按需要添加：

| 日期 / 数据编号 | 检查目的与范围 | 来源、抽样或脚本 | 实际发现与局限 | 处理版本 / 下一步决定 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

涉及具体样本时链接实际数据清单、处理配置或统计结果；数量与比例注明单位和分母，关联患者或其他独立对象与派生记录。

## 设计与测量事实（相关时填写）

| 字段 | 已核实事实 / 依据 / 待确认 |
| --- | --- |
| 目标人群、招募来源与入组 / 排除规则 | 区分样本覆盖与希望推广的人群 |
| 基线、重复测量、随访与结局的时间关系 | 推理时可用信息与未来监督分开 |
| 站点、设备、协议及状态记录 | 例如睡眠/清醒、中断、药物或任务；只记录实际相关项 |
| 组间构成、潜在混杂、缺失与失访 | 不以 P 值不显著证明平衡 |
| 质控依据、盲法、排除及版本 | 保留客观规则与实际偏离，不依预测正确与否删样本 |
| 各子集的职责及跨阶段独立性 | 不完整数据可承担不同角色，但需核查分布差异、重叠与泄漏 |

状态事件尽量链接采集时的记录。敏感标识按权限保存；随机编号不自动等于完全匿名。
