# 科研思维、阶段判断与证据迭代

按当前问题阅读相应部分：

1. 上位问题、围绕问题的文献调研、关键局限、motivation 与价值。
2. 跨领域启发、idea、假设、方法与任务的关系。
3. 七阶段的产出与推进依据。
4. 证据解释、失败诊断与知识贡献。

这份参考保留用户个人思考中的核心关系；它是研究判断的辅助，不是必须逐项执行的清单。

## 1. 从方向走到值得回答的问题

| 层次 | 作用 | 需要形成的认识 |
| --- | --- | --- |
| 研究方向 | 界定工作领域 | 我正在研究什么对象与现象？ |
| 上位问题 | 给课题提供意义 | 领域希望理解或改善什么重要事情？ |
| 具体问题 | 将未知限定到可研究范围 | 在什么条件下，究竟还有什么未回答？ |
| 技术问题 | 说明实现困难 | 为回答具体问题，需要解决什么障碍？ |
| 知识贡献 | 回到原问题 | 研究使我们新增了什么可靠认识？ |

问题可以来自真实需求、已有方法的局限、数据观察、复现、异常或矛盾结果。通过文献和数据检查：这是个人未知，还是已有知识的实际边界？

“现有方法未显式利用信息 A”是设计事实；“所以它不能学到能力 B”是待检验推断。记录时分开陈述，并保留来源。

### 以上位问题为调研锚点

当前课题要说明自己回应上位问题的哪一部分。以此确定检索与比较范围：现有研究分别如何回答这个问题，已经提供了哪些答案，依赖什么数据、监督和条件，哪些地方仍未解决。

先建立主要方法路线的整体认识，再深入关键论文。可以结合综述、代表性与近期工作、简单或经典基线，以及引用和后续工作的追踪；具体覆盖面由问题和资料决定。不要因已选中一种架构，就把同架构论文当成该问题的全部相关工作。

“全面调研”在操作上指对声明范围内的主要路线及关键证据形成充分覆盖。记录范围、来源、已覆盖路线和待补部分；信息不足时继续补证据，不把尚未发现写成无人研究，也不要求读完所有论文才允许形成初步判断。

对每类方法综合：

| 方法路线 | 回答上位问题的哪部分 | 已有贡献与证据 | 所需信息、数据与评价条件 | 剩余困难与适用边界 |
| --- | --- | --- | --- | --- |
| 按实际调研填写 |  |  |  |  |

### 从单篇 limitation 到值得解决的关键局限

单篇卡片积累后，需要跨论文总结。区分方法能力、信息或数据条件、测量与评价等不同来源的困难，避免把不同设定下的结果当作可直接比较。

| 候选局限 | 关联论文与实际证据 | 共性还是特定条件 | 如何限制回答上位问题 | 值得优先解决的理由 / 尚缺证据 |
| --- | --- | --- | --- | --- |
| 明确困难及发生条件 | 作者自述、实验证据与自己的推断分开 |  |  |  |

优先关注有依据、影响重要目标、能够研究的局限。作者 future work 可以启发问题，但不能直接当作已经验证的瓶颈。候选方法不必解决所有论文的全部不足；要说明它针对哪一个重要局限，以及缓解后为何能够推进上位问题。

### 判断价值

考虑重要性、新知识、可研究性和投入合理性：

- 回答会改变什么理解、实践或研究决定？
- 相比已有工作能增加什么，相关工作是否真在相同条件下回答过？
- 什么数据、观察或比较能够减小这个未知？
- 现有条件能获得什么强度的证据，是否应收窄问题？

“没有人试过”与方法组合的新颖性不能独立完成价值论证。负面、边界性或评价方面的发现，也可以贡献知识。

### Motivation

使用论证顺序：

> 什么事情重要 → 已有研究解决到了哪里 → 还存在什么关键未知或局限 → 为什么值得回答 → 基于什么判断开展本研究。

发现问题和判断价值是实际研究活动；motivation 是向读者呈现这些理由。研究的探索顺序可以交错，不能据论文叙述推断作者实际尝试的先后顺序。

## 2. 把 idea 拆清，连接三层结构

| 层次 | 对象 | 要回答的问题 |
| --- | --- | --- |
| 问题层 | 研究问题 | 我想弄清楚什么？ |
| 问题层 | 假设与竞争解释 | 可能的答案是什么，为什么；还可能是什么？ |
| 问题层至实验层 | 方法想法 | 准备作出什么改变，检验或利用哪个判断？ |
| 任务层 | 可观察任务 | 具体输入、输出、测量、评价与泛化是什么？ |
| 实验层 | 数据与比较 | 怎样获得足以区分解释的证据？ |

形成 idea 时，可以从目标、可用信息、数据生成过程和约束出发推理；跨领域借鉴时检查原方法依赖的前提在当前条件下是否成立。实际证据用来校验推理。

### 跨领域启发怎样变成可研究的 idea

从目标局限所对应的困难寻找其他领域的类似问题，例如弱配对、标签不足、异质观测或长时信息整合；再判断其方法为何可能适用。跨领域阅读与本领域调研可以交错推进。

对值得继续的候选方法，建立这条联系：

> 源领域的问题与方法 → 起作用的理由及前提 → 当前局限的相似与差异 → 必要改造 → 可检验预期 → 对上位问题的预期知识贡献。

不能仅因方法在源领域有效就假定迁移成立；方法名称新、模块组合新，也不足以解释研究价值。没有合适迁移前提时，考虑本领域方法或其他检验路径。

一个候选 idea 要连起两端：**缓解一项关键局限，以及因此使上位问题获得更多可靠答案。** 假设和实验负责检查这两个联系，局部指标提升不足以代替它们。

可用的一句话：

> 在【条件】下存在【有依据的困难】。我认为【解释】，因此考虑【改变】；若判断正确，应观察到【结果】，这将有助于回答【具体问题】。

假设可以先粗略，再随文献和探索明确。对于探索性分析，事先说明观察问题和方法限制，把后续产生的解释记为新假设。

### 让假设能够接受证据

对关键判断说明：

1. 什么观察会支持它？
2. 什么观察会削弱它？
3. 哪些竞争解释也能产生相同结果？
4. 哪个比较有助于区分这些解释？
5. 结果不同，会怎样改变下一步决定？

一个假设可能需要多种证据，一个实验也可能影响多个判断。无需机械地一项假设分配一次实验。

### 任务形式化

定义任务目标、预测与样本单位、推理输入、输出及真实答案的测量、训练监督、评价标准、泛化目标，以及指标改善的证据含义。

特别检查：即使任务完成得很好，能支持原研究问题的哪部分？如果还有缺口，需要补充实验或收窄主张。

具体模型结构属于落实方法时的选择。任务层先规定模型应承担的映射与可用信息，不能让选定模型反过来替代问题价值。

## 3. 七阶段及推进依据

| 阶段 | 重点 | 可检查的产出 | 推进依据 |
| --- | --- | --- | --- |
| 发现问题 | 以上位问题组织方法调研，归纳已有答案与关键局限 | 问题与方法地图、跨论文局限综合、文献与观察依据 | 有边界的未知及其来源 |
| 判断价值 | 重要性、新知识、可行性与投入 | motivation、主要可行性判断 | 值得投入且有获得证据的路径 |
| 形成假设 | 结合本领域与跨领域启发，明确判断、前提、方法与竞争解释 | 候选 idea、假设及预期结果 | 连接关键局限与上位问题，知道哪些观察会改变判断 |
| 形式化任务 | 输入输出、监督、评价与泛化 | 任务定义、数据需求 | 任务与研究问题联系明确 |
| 设计实验 | 数据与划分、基线、比较及选择 | 数据版本、比较方案、运行前卡片 | 能获得可解释的证据 |
| 训练与评价 | 实现检查、训练验证和独立评价 | 配置、日志、结果及不确定性 | 可靠性足以支持当前范围的判断 |
| 解释与更新 | 证据、替代解释、局限变化与知识边界 | 结论、决策及新增未知 | 明确给上位问题增加了什么答案、条件或边界认识 |

这是定位表，不是通关表。数据可行性会影响选题，预实验会影响假设，结果也会迫使重新定义任务。

### 记录项目状态

使用：

> 当前主阶段 + 并行工作 + 最重要的不确定性 + 下一项行动与产出 + 完成后准备作的决定。

优先减少会改变课题选择的重要未知。任务要具体，例如“核实独立对象标识并追溯几个原始样本，以决定能否评价新对象泛化”，而不是“整理数据”。

数据尚未准备好的项目，阶段重点可以是可行性。先核实获得了什么、数据层级和监督含义、质量与可用范围，再确定数据是预训练材料、目标任务数据、评价数据或仅能承担部分用途。

## 4. 从结果到判断

### 两个循环

- **学习循环：** 在给定任务、数据和目标下优化参数，经验证选择模型或方案。
- **科研循环：** 提出问题与假设，设计检验，获得证据，比较解释，更新认识。

模型训练是科研循环中可能采用的一种工作。优化稳定不等于泛化好，泛化好也需要合适比较才能支持具体假设。

### 结果不符合预期时

| 线索 | 优先调查 | 当前能得出的判断 |
| --- | --- | --- |
| 数据或处理异常 | 原始样本、单位、标签、关联关系、处理前后变化 | 证据尚不可靠 |
| 实现异常 | 模块连接、损失、梯度、评价聚合 | 可能尚未检验预期方法 |
| 学习未正常工作 | 小规模可信样本、训练曲线、更新设置 | 先区分实现与可训练性 |
| 设计没有区分解释 | 数据独立性、比较条件、指标和原问题 | 改善检验，不能直接判定假设 |
| 波动或选择效应显著 | 抽样、初始化、评估样本及方案选择 | 判断证据是否足够 |
| 可信比较仍不支持 | 适用条件、竞争解释与投入 | 收窄、修改或停止当前路线 |

从最有线索、最早不可靠的环节查起，不把诊断写成无条件的长检查清单。调整参数或实验，应当对应具体不确定性。

### 怎样认定研究形成了贡献

主要问题有价值，实验回应判断，结论有相应证据，合理替代解释得到检查，结论范围与实际检验的条件一致。

用户所说的“扩大知识圈”，可以落实为三项陈述：**研究前已有的答案和条件是什么；本研究可靠地增加了什么；哪些部分仍然未知。** 新的方法、数据、现象、解释或评价发现，都要回到这种认识变化，说明它怎样为领域贡献更多答案。

扩展知识的已知范围不等于必须让方法适用范围变宽。证明某种做法只在特定条件下有效、揭示反例或修正原先过宽的主张，也会增加对上位问题的认识。方法改进时应说明局限得到何种缓解；发现型工作无需硬编一个待修复模块。

有效、条件性有效、证据不足或不支持原假设，都可以成为结论。一次失败运行未必否定科学假设；可靠负面结果也不能只凭没有提升就无限推广。

适时整理：

| 准备提出的结论 | 对应证据 | 剩余解释 | 适用边界与缺少的检验 | 给上位问题增加的答案 |
| --- | --- | --- | --- | --- |
| 当前判断，标明是否为假设 | 论文、数据或实验编号 | 尚未区分的因素 | 人群、任务、数据与评价条件 | 相较已有认识新增了什么 |

Proposal 预先说明问题、价值、判断、任务和获得证据的路径；论文用实际证据回答问题。均不要求先替预定架构编造理由。
