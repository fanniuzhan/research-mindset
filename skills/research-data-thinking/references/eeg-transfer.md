# EEG／HEEDB 专项：把测量与泛化目标对应起来

本文件是通用数据理念向 EEG 的独立迁移，不是来源作者验证过的 EEG 方法。先使用用户的具体协议、任务和已有代码，不能从示例推定其数据属性。

## 采集到实验输入的语义链

优先建立 dataset → subject → session → recording → trial/event → window 的可追溯层级；某个数据源没有 trial 等结构时按其实际组织记录，不虚构字段。

| 需要核对 | 应保存和检查的证据 |
|---|---|
| 被试与来源身份 | 来源命名空间、匿名 ID、允许核查的跨源重叠；身份未知的限制 |
| 幅值与测量单位 | 原单位、缩放系数、设备导出／物理值、范围及前后实例 |
| 通道与参考 | 原名称／顺序、位置、参考电极／重参考、缺失与插值标记；同名不自动同位置 |
| 时间与采样 | 实际采样率、历史变化、采集时钟、事件偏移与漂移；预期和实际记录数 |
| 滤波与重采样 | 频带、抗混叠、相位／边界、事件时间误差、可能改变的目标信息 |
| 分窗 | 原记录与时间区间、重叠、跨 trial／缺失段／划分边界、标签聚合含义 |
| 标签 | 实验操作定义、标注依据、粒度与时点、跨来源语义、一致性和效度 |
| 质量处理 | 伪迹、真实状态与罕见事件的区分；阈值与来源／被试／任务的流失变化 |

离线零相位滤波、双向上下文或整段标准化能否用于实时／未来预测，按使用时可得信息判断，不能仅凭“常用预处理”放行。固定、不依赖全库拟合的逐记录变换可与来源划分独立实施，但派生片段需继承划分；跨记录学习的参数遵守训练范围。

## 评估目标决定隔离单位

| 要支持的目标 | 划分和检查 |
|---|---|
| 已见被试的新会话 | 可允许个体已见，但隔离未来会话的标签和学习式统计 |
| 未见被试 | 同被试所有相关记录放在同侧；检查匿名／跨源身份不确定性 |
| 未见站点／设备／来源 | 按目标域留出，分别说明设备、人群、任务与标签共变 |
| 未见任务 | 写清输入、标签与任务语义是否足以构成有意义的比较 |

重叠窗口、同刺激材料和转换缓存分别核查。少站点时，不把站点 bootstrap 当作可靠普适结论；按被试重采样也不自动覆盖站点层的不确定性。训练种子回答优化波动，不能替代这些泛化证据。

窗口等权、被试等权、来源等权对应不同目标。先确定 estimand／要汇总的量，再选权重。改变训练采样会同时影响数据构成与优化过程，需要解释其可能影响。

## 从迁移失败提出可区分的假说

| 候选解释 | 小实验方向 | 不可直接推出的结论 |
|---|---|---|
| 来源／设备痕迹主导表征 | 来源探针、协议比较、可比子集或同条件配对 | 来源可预测不证明设备造成下游失败；设备可能与任务、人群共变 |
| 标签定义不一致 | 回到协议、审核原始标签与事件，建立任务对应 | 合并类别后涨分不证明科学含义相同 |
| 预训练目标错位 | 同数据／划分／预算下比较目标，观察任务有关信息 | 重构更好不证明解码更好；额外监督可能解释优势 |
| 大源／长记录支配 | 比较按窗口、对象与来源采样，记录贡献和训练稳定性 | 权重变化带来的提升不一定来自所声称的表征机制 |
| 预处理改变了对象构成 | 阈值敏感性、排除前后分组、边界样本复核 | 更干净的剩余子集不自动支持全体人群 |

优先选择会改变下一步决策的解释，用可逆、低成本实验检验。证据指向问题或测量错位时，可以修改研究问题；证据支持表征问题时，再考虑任务对齐、频谱、通道拓扑或跨被试稳定性等具体机制。不预先把“大数据／大模型／新模块”设为答案。
